## 🤔 Apa itu Web3?

| Era | Deskripsi | Kontrol |
|-----|-----------|---------|
| Web1 | Internet hanya bisa dibaca | Perusahaan |
| Web2 | Internet bisa dibaca & ditulis | Google, Meta |
| Web3 | Internet bisa dibaca, ditulis & dimiliki | Pengguna sendiri! |

## 📄 Penjelasan File

### 🌐 pengenalan_web3.py
Pengenalan konsep dasar Web3:
- Perbedaan Web1, Web2, dan Web3
- Kenapa Web3 penting untuk masa depan
- Komponen utama Web3

### 💼 simulasi_wallet.py
Simulasi koneksi wallet ke aplikasi Web3:
- Cara wallet terhubung ke dApp
- Proses tanda tangan transaksi
- Keamanan private key

### 🔍 baca_blockchain.py
Membaca data publik dari blockchain:
- Simulasi block explorer
- Cek harga ETH secara live
- Melihat data transaksi

### 📜 simulasi_smart_contract.py
Simulasi cara kerja smart contract:
- Deposit & transfer token
- Aturan otomatis tanpa perantara
- Transparansi transaksi
